> **University Project** | Introduction to Programming | Group 12

## 🎮 About the Game

**Forger** is a 2D game where the player must forge various documents to complete missions.

The core concept: imagine you need to fake a report for your boss, forge a parent's signature on a school note, stamp an official document, or replicate a signature you've never actually signed. The game revolves around the art of deception — using a variety of forgery tools to create convincing fakes and fool the system.

Planned forgery tools and mechanics include:
- ✍️ **Freehand drawing** — replicate handwriting and signatures
- 🔏 **Stamps** — create and apply official-looking stamps
- 📄 **Document templates** — fill in and modify various document types
- 🖊️ And more methods to be added in future versions...

## 🚧 Current Status — Version 0.1 (Alpha)

> ⚠️ This is the **very first iteration** of the project. Only the core foundation has been implemented so far.

### ✅ What's done:
- **Drawing mechanic** — the player can draw freehand on a canvas using a brush
  - Raycast-based pixel detection
  - Adjustable brush size and color
  - Texture rendering in real-time via Unity's `Texture2D`

### 🔜 Planned for future versions:
- [ ] Document templates and missions
- [ ] Stamp tools
- [ ] Scoring / detection system (how convincing is your forgery?)
- [ ] More forgery tools and gameplay mechanics
- [ ] UI and menus

## 🚀 How to Run

1. Clone the repository
2. Open the project in **Unity 6** or later
3. Open the scene in `Assets/Scenes/`
4. Press ▶ Play and start drawing!
